# 05 — ICONS & ILLUSTRATION

Nghiên cứu từ Noun Project, SlidesCarnival, thói quen template Slidesgo.

## 1. Nhất quán bộ icon (quan trọng nhất)

Một deck chỉ dùng **1 họ icon** — 1 nguồn, 1 style. Trộn icon nhiều nguồn là lỗi phổ biến nhất làm deck "rẻ tiền".

Tiêu chí đồng nhất khi chọn:
- **Stroke weight** như nhau (đều 2px hoặc đều solid/filled — không trộn outline với filled).
- **Corner radius** như nhau (đều bo tròn hoặc đều góc vuông).
- Cùng hệ tỷ lệ (đều square viewBox).
- Cùng màu: mono theo màu chữ, hoặc 2 màu theo palette.

Nguồn: Canva Elements (tìm "icon + [chủ đề]" rồi lọc cùng bộ), Phosphor Icons, Noun Project, Flaticon (đảm bảo license).

## 2. Icon grid (lưới icon)

- Chuẩn: **3 hoặc 4 icon** hàng ngang/giảng giải bước; tối đa 5.
- Mỗi icon có **label** ngay dưới (2-4 từ) — icon không bao giờ tự nói ý.
- Kích thước icon bằng nhau tuyệt đối (vd đều 96×96px), khoảng cách đều (grid).
- Kèm 1 dòng mô tả 24-28px dưới label nếu cần — nhưng nhớ 6×6 rule.
- Icon + label + mô tả → **group** lại để animate 1 click.

## 3. Illustration

- Chọn 1 style: flat / outline / 3D clay / hand-drawn — KHÔNG trộn trong cùng deck.
- Illustration làm **điểm nhấn** (1 ảnh lớn 1 slide), không rải lác đác.
- Ưu tiên illustration cùng palette với deck (Canva Elements lọc theo màu).
- Tránh illustration "stock generic" (người cờ-lê, đồng hồ, bong bóng chat vô nghĩa).

## 4. Bảng quy đổi icon → ý nghĩa
| Nội dung | Icon gợi ý |
|---|---|
| Đặc điểm/tính chất | star, badge, check |
| Quy trình | arrow, numbered circles |
| Thời gian/lịch sử | timeline dot, hourglass |
| Con người/cộng đồng | users, handshake |
| Địa lý | map pin, globe |
| Văn hóa | lantern, mask, hoa văn riêng đề tài |

## 5. Tránh
- Icon quá chi tiết khi thu nhỏ <48px.
- Dùng emoji thay icon trong deck trang trọng.
- Icon màu đủ 7 sắc cầu vồng — neo vào palette.
- 2 icon cùng slide cùng ý nghĩa (bỏ 1).
